# 交付计划

1. 官方资料研究、信任边界、失败恢复及仓库配置。
2. 纯托管认证核心、持久化模型、受限协议、隔离安全测试。
3. Yubico 硬件适配、SYSTEM DPAPI 仓库、Windows 服务、账户绑定及维护。
4. 原生 V2 Credential Provider，异步硬件等待及自动提交，保留所有系统入口。
5. 简体中文 WinUI 3 管理器，真实状态、绑定、备份钥匙、密码更新、暂停与撤销。
6. 可回滚安装/卸载、紧急禁用、构建发布、CI、完整操作文档。
7. 构建、安全测试及验证结果归档。

集成验收覆盖安装回滚、设备绑定与触摸、MSA 在线/离线/重启/锁屏、多用户、故障恢复、安全桌面取消、App Verifier 及签名发布，见 [验收矩阵](acceptance.md)。
