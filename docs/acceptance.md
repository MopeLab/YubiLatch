# 集成验收矩阵

测试环境：Windows 11 x64 设备或支持 USB 直通的 VM、测试 MSA、两把 OTP2 空闲钥匙。准备原生登录方式、备用管理员账户、BitLocker 恢复密钥和 WinRE。

| 类别 | 场景及通过条件 | 验证状态 |
| --- | --- | --- |
| 账户 | OOBE 后的 MSA、Hello-only 本机选项、真正无密码 MSA：实际支持或明确拒绝，保留系统方式 | 未执行 |
| 登录 | 重启、冷启动、注销、在线/离线缓存：触摸后正确 SID 登录 | 未执行 |
| 解锁 | 锁屏、睡眠唤醒、多会话、切换用户：只解锁对应账户，取消不提交 | 未执行 |
| 设备 | 5C NFC USB、拔插、多端口、错钥匙、伪造序列号：必须验证真实响应 | 未执行 |
| 备份 | 主/备钥匙分别成功，两把同时插入拒绝歧义 | 未执行 |
| 触摸 | 无触摸、超时、取消后重试、切换 PIN：不静默登录、不复用取消响应 | 未执行 |
| 配置 | OTP2 占用拒绝覆盖；OTP1/FIDO2/OpenPGP/PIV 前后相同 | 未执行 |
| 槽位保护 | 非管理员不能无管理码改 touch；官方工具可凭管理码恢复槽位 | 未执行 |
| 绑定 | 错误密码、另一账户密码、写入前/后断电：SID 校验与 pending 恢复 | 未执行 |
| 改密 | 云端改密、缓存变化、账户锁定/到期：Windows 最终验证，停止重复尝试 | 未执行 |
| 服务 | 启动失败、停止、崩溃、SDK 卡顿：无凭据泄漏，可用系统登录 | 未执行 |
| IPC | 低权限、其他会话、远程管道、伪造服务、畸形数据/慢连接：无越权、可恢复 | 未执行 |
| 安装 | 权限不足、损坏包、重解析点、服务失败：正确回滚，无半注册 Provider | 未执行 |
| 卸载 | DLL 使用中、保留数据重装、清除数据、重复卸载：先禁用，明确清理结果 | 未执行 |
| 恢复 | 丢失全部钥匙、密文损坏、DPAPI 失效、WinRE 离线禁用：原生路径实际可用 | 未执行 |
| 原生可靠性 | App Verifier、内存与竞态、安全桌面超时：无崩溃或死锁 | 未执行 |
| 发布 | Authenticode、WDAC/杀毒兼容、可信分发包 | 未执行 |
| 界面 | 深浅色、高对比、100–200% DPI、键盘、Narrator、窄窗口：内容可达、状态真实 | 部分检查 |

验收记录包括 Windows 版本和策略、SDK、钥匙型号与固件、操作步骤、实际结果和脱敏错误码。
